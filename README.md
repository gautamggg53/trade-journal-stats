# trade-journal-stats

[![CI](https://github.com/gautamggg53/trade-journal-stats/actions/workflows/ci.yml/badge.svg)](https://github.com/gautamggg53/trade-journal-stats/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Performance statistics for a closed-trade history, from the command line or
Python. Point it at a trade export (MT5, cTrader, TradingView or a simple CSV)
and get net P&L, win rate, payoff ratio, profit factor, expectancy in money and
in R, closed-equity drawdown with duration, streaks, Sharpe/Sortino, breakdowns
by symbol, side, session, weekday and hour, and a monthly P&L table.

- Runs locally; your statements never leave your machine.
- No runtime dependencies beyond the Python standard library (plus `tzdata` on Windows).
- Output as a terminal table, JSON, CSV, or a single self-contained HTML file
  with an SVG equity curve (no external scripts, fonts or CDNs).
- Every formula is written down in [docs/METRICS.md](docs/METRICS.md) and the
  maths is tested against hand-computed values.

> **Not financial advice.** This tool describes what already happened in a
> trade history. It does not predict results or recommend trades. Check the
> numbers against your broker statement before relying on them.

## Install

```bash
pip install git+https://github.com/gautamggg53/trade-journal-stats
```

Python 3.10+. (Not on PyPI yet.)

```bash

trade-stats trades.csv --from 2026-04-01 --to 2026-04-30 --symbol EURUSD --json
```

## Input formats

The format is auto-detected from the header row; override with `--format`.

| Format | What to export | Verified against |
| --- | --- | --- |
| `generic` | A CSV you write yourself (spec below) | This repo's spec and tests |
| `mt5` | MT5 desktop: History tab, right-click, Report, HTML. The Positions table saved as CSV also works | **Public descriptions only.** Not yet checked against a real exported report |
| `ctrader` | cTrader History tab, Statement, CSV | **Column names from the [cTrader History help page](https://help.ctrader.com/ctrader/trading/history/)** and third-party import guides. Not yet checked against a real file |
| `tradingview` | Strategy Tester, List of Trades, Download (CSV) | **Public descriptions of both the older (`Trade #`, `Profit USD`) and newer (`Trade number`, `Net P&L USD`) headers.** Not yet checked against a real file |

All fixtures in `tests/fixtures/` are synthetic files written to match those
descriptions. If your export does not parse, please open a "New or changed
export format" issue with the header row and a few **redacted** rows.

How each format is read:

- **MT5:** net P&L = Profit + Commission + Swap from the Positions table. Times
  are broker server time with no zone, so pass `--source-tz` (often `+02:00`/
  `+03:00`). The `S / L` column (stop at close) is used for R when present, so R
  is approximate if you moved your stop.
- **cTrader:** uses the `Net <currency>` column (or `Net USD`, or Gross +
  Commission + Swap as a fallback). A zone in the header such as
  `Closing time (UTC+2)` is applied automatically. Dates like `05/01/2026` are
  read day-first; use `--date-format` otherwise.
- **TradingView:** entry and exit rows are paired by trade number; trades still
  open are skipped. The file has no symbol column (`--default-symbol`) and times
  are in the chart's timezone (`--source-tz`).

### Generic CSV

One row per closed trade. Column names are case-insensitive.

| Column | Required | Meaning |
| --- | --- | --- |
| `close_time` | yes | When the trade closed, e.g. `2026-01-05 10:00` (ISO 8601 with offset also works) |
| `pnl` | yes | Net result in account currency, after commission and swap |
| `id`, `symbol`, `side` | no | `side` is long/short/buy/sell |
| `open_time` | no | Used for weekday/hour/session buckets and the start of the equity curve |
| `volume`, `entry_price`, `exit_price` | no | |
| `stop_price` | no | With entry/exit price and side, gives a price-based R |
| `risk` | no | Money at risk when the trade was opened; gives R = pnl / risk |

Semicolon- and tab-separated files are accepted. Values that contain both `.`
and `,` (such as `1.234,56` or `1,234.56`) are read correctly either way, and so
is a lone comma that can't be thousands grouping (`12,5` or `0,125`). Use
`--decimal-comma` when values like `1,234` mean 1.234 rather than 1234.

## Options

```text
--format {auto,generic,mt5,ctrader,tradingview}
--source-tz TZ        timezone of naive timestamps in the file (default UTC)
--tz TZ               timezone for reporting, filters and buckets (default: --source-tz)
--date-format FMT     strptime format, e.g. '%m/%d/%Y %H:%M'
--from / --to DATE    filter on close date (inclusive, in --tz)
--symbol SYM          only these symbols (repeatable)
--balance N           starting balance: enables drawdown % and Sharpe/Sortino
--risk-per-trade N    fixed money risk for trades without their own risk/stop
--json [PATH]  --csv [PATH]  --html PATH  --title TEXT
```

## Library use

```python
from trade_journal_stats import load_trades, compute_report

history = load_trades("trades.csv", source_tz="Europe/Athens")
report = compute_report(history.trades, balance=10_000)
print(report.profit_factor, report.max_drawdown.amount)
```

## Limitations

- Closed trades only. Floating (open-trade) drawdown cannot be measured from
  these exports, so prop-firm style equity drawdown can be larger than shown.
- Deposits and withdrawals are not modelled. `--balance` is one starting value.
- Partial closes are whatever the export lists: MT5 Positions and cTrader rows
  are taken as they are; TradingView rows are paired by trade number.
- One account currency per file is assumed; mixed-currency files are not converted.
- Sessions are fixed UTC windows that ignore daylight saving.
